# 🔐 Caesar Cipher — 4 languages

A classic encryption tool that shifts letters by a fixed number.  
Implemented in **Python**, **JavaScript (Node.js)**, **C++**, and **Go**.

## 🚀 Run

| Language | File | Run command |
|:---|:---|:---|
| Python | `python/caesar.py` | `python caesar.py` |
| JavaScript | `javascript/caesar.js` | `node caesar.js` |
| C++ | `cpp/caesar.cpp` | `g++ caesar.cpp -o cipher && ./cipher` |
| Go | `go/caesar.go` | `go run caesar.go` |
